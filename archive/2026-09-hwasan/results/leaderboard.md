## Notes

- **List $ /ch** is what one chapter costs at the provider's list price: the tokens each call recorded, priced from the roster (OpenRouter list), or the route's own list-price figure where it reports one. It compares every model on one basis, whatever route ran it. Reasoning is billed as output, so **Out tok /ch** includes it. CLI routes carry their harness's own input overhead. **Value** is composite points per list dollar per 1,000 source characters.
- **Billed `sub`** means a subscription covered the call, so it billed zero. That is not the same as the model being free to run. **`N/A`** means the access path reports no cost at all. Neither is a price.
- **Slop** counts LLM-tell and translationese phrases per 1,000 words. **Repetition** is top-n-gram concentration. Neither enters the composite; both are diagnostics.
- Model behavior changes under a stable name. These results describe the versions tested on 2026-10-22.
